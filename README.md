# Lista de exercícios Python - Sistemas Distribuídos e Mobile
Lista de Exercícios da disciplina Sistemas Distribuídos e Mobile da UniBH.

Correções:

1. Você pode usar a estrutura if sem ()
2. Você pode usar, por exemplo, "if 0 <= valor <= 100:"
3. A boa prática para classes é fazer um arquivo para cada classe e fazer o nome do arquivo igual o nome da classe. Para Python isso não faz tanta diferença, mas para outras linguagens, como Java, pode ser que dê erro.
